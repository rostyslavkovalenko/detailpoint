# DetailPoint — Car Detailing Website

A responsive presentation website for a fictional car detailing studio based in Gdańsk, Poland.

**Live Demo:** https://detailpoint.vercel.app/

## About the Project

DetailPoint is a portfolio project created to practice building modern, responsive websites using HTML, CSS, and JavaScript.

The website presents car detailing services, showcases example projects, and provides a contact page.

## Pages

* **Home** (`index.html`) — introduction to the studio and an overview of its services.
* **Services** (`services.html`) — a presentation of available detailing services.
* **Gallery** (`gallery.html`) — example car detailing projects.
* **Contact** (`contact.html`) — contact information and a demonstration contact form.

## Technologies

* HTML5
* CSS3
* JavaScript
* Git and GitHub

## Features

* Responsive layout for desktop and mobile devices.
* Mobile navigation menu.
* Multi-page website structure.
* SEO metadata and Open Graph tags.
* Custom favicon and social sharing image.
* Contact form interface.

> **Note:** The contact form is currently a frontend demonstration. Message submission has not been configured.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rostyslavkovalenko/detailpoint.git
   ```

2. Open the project folder:

   ```bash
   cd detailpoint
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No build tools or package installation are required.

## Deployment

The website is hosted on Vercel and connected to the GitHub repository. Updates pushed to the `main` branch trigger automatic deployments.

## Project Status

The main website pages, responsive layout, and navigation are implemented. The contact form still requires a submission service or backend integration.
